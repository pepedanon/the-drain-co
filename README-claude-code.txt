# The Drain Co — website handoff for Claude Code

## What this is
A complete redesigned website for The Drain Co (plumbing & drain cleaning, Greater Los Angeles).
`the-drain-co-homepage-concept.html` is the entire site in ONE self-contained HTML file
(all pages are hash-routed views: Home, Plumbing, Drain Cleaning & Sewers, Emergency,
About, Thelma, Tips, Contact; all assets inlined).

## Deploy on Vercel
Single-file deploy: serve this HTML as `index.html`. No build step, no dependencies.
